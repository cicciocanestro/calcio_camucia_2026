# Calcio Cortona 2026/2027 • Partite in Casa & Calendario Seconda Categoria

Dashboard web interattiva per gli appassionati di calcio del **Comune di Cortona (AR)**. Raccoglie in tempo reale il calendario delle partite in casa e il tabellone ufficiale FIGC/LND per la stagione sportiva **2026/2027**.

## 🏟️ Squadre & Categorie del Comune di Cortona

- **Cortona Camucia** – *Promozione (Girone C)* • Stadio Comunale "Santi Tiezzi", Camucia
- **Fratta Santa Caterina** – *Seconda Categoria (Girone LND)* • Campo Sportivo "A. Faralli", Fratta
- **Fratticciola** – *Seconda Categoria (Girone LND)* • Campo Comunale, Fratticciola
- **Monsigliolo** – *Terza Categoria Arezzo* • Campo Sportivo "R. Burzi", Monsigliolo
- **Montecchio** – *Terza Categoria Arezzo* • Campo Sportivo Montecchio Vesponi

---

## ⚡ Caratteristiche Principali

- **Calendario Casalingo Completo**: Visualizzazione di tutte le gare in casa delle 5 società del territorio.
- **Evidenziazione Derby Comunali**: Le sfide stracittadine (Fratta vs Fratticciola e Monsigliolo vs Montecchio) sono messe in risalto con badge animati in oro/fuoco e filtro dedicato *"Solo Derby"*.
- **Tabellone Ufficiale Seconda Categoria**: Modale interattivo per consultare tutte le 15 giornate complete (Andata e Ritorno, 8 partite per giornata) conformi al calendario ufficiale LND Toscana.
- **Filtri Multipli**:
  - Filtro istantaneo per singola squadra;
  - Filtro temporale per Mese (da Settembre 2026 a Maggio 2027);
  - Ricerca per data esatta;
  - Ricerca testuale rapida (avversario, categoria, impianto sportivo).
- **Design Mobile-First**: Realizzato con Tailwind CSS e FontAwesome, ottimizzato per smartphone, tablet e desktop.
